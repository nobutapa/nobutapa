A software philosophy

NOBUTAPA Manifesto

NOthing BUt TAlent and PAssion

Beyond agile. Beyond software craftsmanship.
Beyond vibe coding.

Great software starts with people.
With talent. With passion.

Processes help. Tools help. AI helps.
They are multipliers, not engines.

The best toolchain or project method cannot make up for a lack of talent and passion.

Talent finds the simple solution behind the complicated one. Passion cares enough to keep looking.

Scrum, TDD, clean code, pair programming, copilots and agents amplify what is already there. They cannot replace it.

Let the tools be tools.
Trust talent. Cultivate passion.

A software philosophy by Jérôme Leleu.
